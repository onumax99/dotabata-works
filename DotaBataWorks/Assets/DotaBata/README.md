# ドタバタワークス（仮称）プロトタイプ

企画書のロードマップ第1段階「プロトタイプ」にあたる実装です。
仮キャラ1体とグッズ工場1ステージで、「1人でもドタバタが楽しいか」を確かめるためのものです。

## 遊び方

1. `Assets/DotaBata/Scenes/GoodsFactory.unity` を開く
2. メニュー **DotaBata → ゲームビューを縦画面（1080×1920）にする**
3. 再生して「ふつう」か「やさしい」を選ぶ

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 画面の下半分をドラッグ | WASD / 矢印キー |
| アクション（とる・おく・つくる・出荷・すてる） | 右下の大きいボタン | スペース |
| ダッシュ | その左のボタン | 左Shift |

流れ：材料棚でパーツを取る → 組み立て台で長押し → 注文の色の色塗りマシンに入れる（自動）→
ベルトで上へ流れる → 梱包台で長押し → 出荷口へ届ける。

## 調整するところ

ステージの中身は `Assets/DotaBata/Data/GoodsFactory_01.asset`（LevelData）にまとまっています。

- **ルール**：制限時間、★に必要なスコア、注文の待ち時間、得点と減点
- **部品の配置**：どのプレハブをどこに置くか、ベルトの長さ
- **注文表**：何秒後に、どのグッズを何色で出すか
- **ギミック設定**：ベルト逆回転・注文ラッシュ・応援タイムの時刻と長さ

ステージを増やすときは、このアセットを複製して中身を変え、シーンの `Game` オブジェクトの
`GameManager > Level` に差し替えます。

持ち場ごとの数値（組み立て・色塗り・箱づめにかかる秒数、ベルトの速さ、移動速度など）は
`Assets/DotaBata/Prefabs/` の各プレハブにあります。

## フォルダ

| 場所 | 中身 |
| --- | --- |
| `Scripts/Core` | 進行（GameManager）、注文（OrderManager）、ステージ組み立て、カメラ、入力、ガイド |
| `Scripts/Stations` | 持ち場（材料棚・作業台・ベルト・出荷口・ゴミ箱）とグッズ |
| `Scripts/Player` | 操作キャラ |
| `Scripts/UI` | HUD、タッチ操作 |
| `Scripts/Debug` | 自動プレイと確認用の入口 |
| `Shaders` | トゥーン調シェーダー（2段の陰影＋アウトライン） |
| `Editor` | 素材一式を作り直すツール |

## 作り直しツールについて

メニュー **DotaBata → プロトタイプを作り直す** は、マテリアル・プレハブ・LevelData・シーンを
コードから作り直します。**同じ名前のアセットは上書きされる**ので、プレハブや LevelData を
手で調整したあとは実行しないか、先に複製しておいてください。

## 仮のもの（本制作で差し替える）

- 見た目はすべて Unity のプリミティブ。キャラは特定のタレントに似せていない仮キャラ
- 効果音はコードで作った電子音。BGM とボイスはなし（セリフは文字で表示）
- 文字は端末の日本語フォント。製品では専用フォントを入れる
- シェーダーは手書きの HLSL（企画書の方針は Shader Graph）
